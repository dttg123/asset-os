ASSET OS 현재 인수인계
최종 갱신: 2026-10-02

[현재 운영]
- 릴리스: v0.6.14
- 공개 주소: https://dttg123.github.io/asset-os/
- 기준 브랜치: main
- 전체 61개 런타임 TypeScript 소스 any 제거·재도입 방지 및 20261002-6 빌드
- 실제 병합·배포 성공 여부는 GitHub Actions와 공개 서비스에서 확인한다.
- 운영 데이터와 QA 데이터는 분리하며 QA 종료 후 테스트 데이터는 0건으로 정리한다.

[현재 자동 QA]
- 단일 기준 문서: docs/QA_POLICY.txt
- 실행 프로필: qa:fast, qa:core, qa:full, qa:release
- PR과 main push에서 GitHub Actions가 자동 실행된다.
- Node 회귀, 30년 순차 입력, 35년 격리 생성, 스키마 4~21 복원,
  Playwright 데스크톱·Galaxy 뷰포트, 비밀값·타입·생성물·의존성 검사를 포함한다.
- 과거 실행 로그, 스크린샷, 백업 ZIP은 저장소에 보관하지 않는다.
- 실패 증빙은 GitHub Actions artifact로만 보관하고 보존기간이 지나면 자동 삭제한다.

[파일 원칙]
- tests/: 현재 회귀 테스트만 유지한다.
- tests/fixtures/: 현재 QA에 필요한 고정 입력만 유지한다.
- qa-manual.html, qa-mode.js, qa-layout.html: 운영 데이터와 격리된 수동 QA 도구다.
- qa-evidence/: 로컬 임시 결과 전용이며 Git에 올리지 않는다.
- 날짜별 FINAL QA 문서와 구버전 RELEASE 문서는 만들지 않는다.

[변경 절차]
1. 기능 수정
2. npm run qa:core
3. 필요 시 npm run qa:release
4. PR CI 통과
5. main 병합
6. Pages 배포와 공개 릴리스 버전 확인

[주의]
- 자동 QA 파일은 오류 재발 방지 자산이므로 단순히 개수를 줄이기 위해 삭제하지 않는다.
- 실제 계정·실제 기기에서만 확인 가능한 항목은 자동 PASS로 기록하지 않는다.
- 운영 원장이나 Supabase 데이터를 QA 데이터로 덮어쓰지 않는다.

[TypeScript 상태]
- typed-sources.json에 운영 원본 61개가 등록되어 있다.
- @ts-nocheck / @ts-ignore는 0건이며 재추가 시 빌드가 실패한다.
- 전체 61개 런타임 소스에서 any 재도입을 빌드·회귀 검사로 차단한다.
- 남아 있던 18개 모듈의 상태·원장·조회 응답·DOM·AI 분석파일 계약을 보강했다.
- 레거시 추가 필드는 unknown으로 보존하고 계산·출력 시 구체 타입으로 확인한다.
- TS 원본 자체를 VM에서 실행하지 않는다. 동작 테스트는 생성된 JS를 실행한다.

[모바일 백업 확인]
- 저장 위치 선택 미지원 시 다운로드 버튼과 안내를 표시한다. HTTPS 여부만으로 지원을 보장하지 않는다.
- 브라우저 CI에서 실제 ZIP 다운로드·복원 파서, 공유 API 성공·취소·권한 거부, 진동 설정을 확인한다.
- 공유·진동 API 응답은 테스트에서 주입하므로 실제 Galaxy 공유창·진동·설치 확인을 대체하지 않는다.
