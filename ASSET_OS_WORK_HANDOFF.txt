[주의/미해결]
- 공식 확인 결과 Supabase는 Google provider token을 자동 갱신하지 않음. 장기 무인 Drive 백업은 provider_refresh_token과 신뢰 서버가 필요하며, 현재 클라이언트 access token만 저장하는 초안은 사용 금지.
- Android 브라우저는 폴더 접근 API 지원 여부가 다르므로 파일 공유/다운로드 대체 경로가 필요함.
- v0.4 초안 런타임은 본문 로딩 후 게이트, 함수 monkey patch, 불완전 캐시 목록 문제가 있어 그대로 사용하지 않음.
- 현재 안전하게 제공하는 Drive 경로는 Android 공유 시트의 Drive 저장이며, 무인 장기 자동 Drive 업로드 완료로 표시하지 않음.
