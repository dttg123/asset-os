## 새로 재현하여 수정한 문제

1. ISA 빠른 입력 안의 보유내역 등록 버튼 무반응. 메인 화면과 동일한 선택자를 쓰면서 메인 버튼에만 이벤트를 연결하던 문제를 수정했다. 배포 후 빠른 입력 경로를 두 번 열어 등록 폼 진입을 확인했다.
2. ISA 거래의 배당 필터에서 ETF 분배금 제외. 분배금 1,000원과 2,000원을 직접 기록해 전체 거래에는 있지만 배당 필터는 0건인 상황을 재현했다. 수정 후 같은 필터에서 2건을 두 차례 확인했다.
3. ETF 분배금의 재투자 연결 상세가 '연결된 배당 0원'으로 표시됨. 주식 배당과 분배금을 함께 처리하여 '연결된 매수 · 10,000원'으로 수정했다.
4. 월 현금흐름 상세에서 환불·외부 결제·외부 계좌 납입·기타 출금 누락. 월 요약의 거래 범위와 맞추고 환불은 음수로 표시했다. QA 2040년 3월 보험 환불 -10,000원을 상세에서 확인했다.
5. 보험 종료 후 과거 달력의 완료 일정 사라짐. 비활성 일정도 실제 납부가 연결된 과거 발생분은 표시한다. 미납 예정분을 새로 만들지 않는다. 종료/일시납 보험 상세의 납부 일정 문구도 수정했다.
6. 파일 공유 미지원 환경에서 AI 자료를 꺼낼 방법 없음. 검토 화면에 '분석파일 다운로드'를 추가했다. 기존 공유 버튼과 데이터 검증 조건은 유지한다.
7. ISA 이자·출금처럼 종목이 없는 거래 제목의 같은 문구 반복을 제거했다.

## 수행한 실사용 검사

- 지난 30년 QA 백업 1,512건을 화면의 복원 버튼으로 불러왔다.
- ISA 테스트 ETF를 화면 폼으로 등록했다. 초기 현금 100,000원, 10주 × 10,000원, 누적 납입 기준 200,000원이다.
- 분배금 1,000원/2,000원 두 건, 각각 이어서 매수 1주 × 10,000원 두 건, 매도 1주 × 11,000원, 예수금 이자 100원을 입력했다.
- 출금 500원 두 건을 기록하고 두 건 모두 취소했다. 취소 확인창에서 철회도 두 번 실행했다. 원본 8개 거래 중 취소 거래 2개가 백업에 보존됐고, 최종 ISA 평가액 204,100원이 맞았다. 분배금 수정 이력과 취소 거래의 새 거래 만들기 화면도 확인했다.
- 현금·예금·적금·ISA·연금저축·IRP 상세, 소비 고정비·변동비·카테고리, 자산추이 기간, 연금 종목 상세 및 수령분석 기간/모드를 반복 조작했다.
- 연금 나스닥/AI 테스트 종목의 분배금·배당·이자·기타 권리를 각각 두 번 검색했다. 유형마다 두 계좌의 2건씩 표시됐다.
- 연금 거래 입력의 유형·계좌 선택, 작성 중 취소/계속 작성/버리기를 확인했다.
- 종료 보험 수정 후 2034~2060년 27개 연도의 2월 일정 확인: 2034년 실제 완료 1건만 남고 이후 연도에 새 일정이 생기지 않았다.
- 환불 상세 수정 후 2040~2060년 21개 연도의 3월 확인: 환불 -10,000원은 2040년에만 표시됐다.
- AI 파일을 두 번 다운로드하고 실제 JSON 내용이 리밸런싱 0원, QA 계좌, 현재 테스트 보유내역과 일치하는지 확인했다. 입력 수정 후 추가매수 100만원 검토 화면도 확인했다.
- 360px·412px 프레임에서 수정된 배당 목록 가로 넘침 없음. 412px 분배금 상세 스크린샷을 저장했다.
- 최종 QA 백업은 1,520건이며 ZIP 무결성 검사를 통과했다. 수령·매수·취소 이력과 기존 30년 기록을 보존했다.
- node --test 85/85 통과. 조회한 앱 콘솔 오류 0건(브라우저 확장 자체 오류는 제외).
