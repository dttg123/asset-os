# v0.6.2 수정·재검사 보고

2026-09-20. 운영 주소 https://dttg123.github.io/asset-os/ . 표시 버전 v0.6.2, 내부 캐시 식별자 20260920-4. 운영 원장 변경 없음. QA는 2031~2060년 가상 사용 기록이며 예상 급여나 미래 법령 예측이 아니다.

## 수정·배포

- 변동금리 상품의 과거 구간별 이자 계산. 마지막 금리가 0%여도 이전 이자를 보존한다. 같은 적용일 금리는 중복 추가 대신 갱신한다.
- 상품 만기·중도해지 정산은 원금·이자·손실 기록 전체를 검증한 후 저장한다. 오류가 있으면 부분 저장하지 않는다. 종료 후 재정산과 잘못된 날짜·금액을 차단한다.
- 대출 일부상환·완납에 실제 중도상환수수료를 별도 기록한다. 원금과 소비를 구분한다.
- 보험의 실제 납부 기록 경로 추가. 일시납·종료 계약 표시 개선. 연결 보험료를 수정해도 연결 관계를 유지하고, 환불을 실제 납부 누계에서 차감한다.
- 환불 저장 후 해당 월 거래 목록으로 이동한다. 다른 달 필터 때문에 방금 저장한 환불이 숨겨지는 문제를 수정했다.
- 종료 ISA 거래 목록에 통합 원장의 납입 36건을 연결하고, 연금 이전 후 남은 현금 수령액도 표시한다.
- 제도 버전 저장과 적용을 분리하고, 연금·IRP에도 시행일 이전 적용 차단을 적용했다. 적용 이력으로 이전 연도 계산 기준을 보존한다. 미래 제도는 QA 가정일 뿐 실제 법령으로 제시하지 않는다.
- 닫힌 패널이 화면 터치를 가로채지 않도록 수정했다. 제도 세율 소수점 표시를 정리했다.

## 실제 확인

기존 화면 입력 1,497건에 추가 시나리오를 반영한 최종 QA는 1,512건이다. 최종 ZIP 다운로드와 복원 후 1,512건 및 순금융자산 798,562,010원이 유지됐다. ZIP 내부 JSON의 무결성도 확인했다.

| 연도 재검사 | 상품 수정 후 2035~2060년 26개 연도, 환불 후 2040~2060년 21개 연도, 대출 종료 후 2042~2060년 19개 연도의 해당 월 확인 |

## 남은 제한과 개선 후보

**모든 세부 버튼·모든 오류 분기를 각각 2회 이상 확인했다는 전수 완료 판정은 하지 않는다.** 주요 흐름을 반복 확인했으나 전체 버튼 인벤토리와 성공 결과를 일대일로 대조한 완전한 증거는 없다.

- 실제 Android 공유창에서 ChatGPT로 파일 전달, Google 로그인·클라우드 동기화, KIS 실계좌 지급유형·최신 시세는 QA 차단 영역이다. 실제 전송·조회 성공으로 보고하지 않는다. 브라우저의 AI 공유는 미지원 안내까지 확인했다.
- 모바일 너비는 프레임 기반 CSS 검사이며 실제 휴대폰 키보드·터치·PWA 생명주기 검사를 대신하지 않는다.
- 연금 수령기 인출·계좌 이전 전용 흐름, 완료한 금융상품 정산의 안전한 정정/되돌리기는 장기 사용 보강 후보다. 이번에 구현·검증했다고 보고하지 않는다.
- 공유 미지원 환경에서는 분석파일 다운로드를 명시적으로 제공하면 사용성이 좋아진다. 외부 앱 전송 성공과 자료 생성 성공은 구분해야 한다.
- 새 그래프·뉴스·상품추천·예상 월급 추가는 불필요하다. 기능 삭제보다 긴 설명과 드물게 쓰는 관리 기능을 상세에 유지하는 방향이 적절하다.

이 보고는 이전 manual-30-year.md의 미지원 목록 중 이번에 해결한 항목을 갱신한다. 이전 보고의 당시 발견 사실을 지우지는 않는다.
