# 통합 화면 정돈 — v0.7.14 / 20261026-1

## 화면 역할
- 전체 자산은 홈에 유지한다. 통합 전체는 선택한 월의 현금흐름·소비·남은 납부 요약이다.
- 거래의 분류별 묶음을 유지하며 필터는 가로 한 줄씩, 적용 조건과 초기화를 표시한다.
- 소비 기간은 월·분기·반기·연간 네 가지다. 여러 해 비교는 연간 내부에 둔다.

## 변경
- 월 소비를 일별 선 그래프로 표시하고 날짜 눈금을 그래프와 분리했다. 정확한 날짜는 그래프 또는 날짜 선택으로 조회한다.
- 분기·반기에는 월 막대와 축약 금액을 함께 표시한다. 연간 12개월은 가로 스크롤 없이 한 화면에 표시한다.
- 금액 축과 음수 환불을 표시하고 미도래 기간과 과거 0원을 구분한다.
- 선택한 기간의 날짜·금액·분류별 내역은 고정된 작은 영역에 표시한다. 큰 파란 상세 상자를 제거했다.
- 카드의 확정 청구 중 남은 납부액을 우선 강조한다. 청구 전 예상은 별도 표시하며 카드별 실제 청구일(없으면 예정일)을 표시한다.
- 일정은 납부 분류를 먼저, 수입 예정을 별도로 표시한다. 완료 기록은 접은 상태로 유지한다.
- 거래 입력 순서를 금액·거래 종류·대상·날짜·항목·분류로 정리하고 중복 수입 입력 버튼을 줄였다.

## 이전 QA의 누락 원인
기존 검사는 기간별 데이터 개수·합계·상세 연결과 가로 스크롤 동작을 확인했다. 이 기준은 일별 마지막 날짜가 읽히는지, 연간 전체가 한 화면에서 비교되는지, 기간 탭의 의미가 분명한지를 보장하지 못했다. 새 회귀검사는 좁은 폰·일반 폰·태블릿 및 밝은/어두운 테마에서 실제 눈금 경계와 그래프 너비, 선택 금액·상세 합계, 보기 전환 시 금융 원본과 저장 revision 보존을 검사한다.

## 데이터 범위
계산·회계·저장·백업 스키마는 변경하지 않았다. QA는 격리된 합성 데이터로 진행하며 사용자 운영 데이터를 입력하거나 수정하지 않는다. Android 실기기 직접 조작 검증과는 구분한다.

## 추가 회귀 수정 — build 20261026-2
분류 저장이 느릴 때 사용자가 창을 닫고 이동하거나 새 입력을 열면, 완료 콜백이 이전 상세를 다시 열 수 있었다. 저장 시작 시의 창 상호작용 토큰과 폼 연결 상태를 확인해 이전 창의 후속 동작을 취소하고 현재 화면만 갱신한다. 분류 저장은 유지하며 금융 거래 원본은 변경하지 않는다. 지연 저장을 강제로 재현하는 검사로 이동한 화면과 새 입력 금액의 보존을 확인한다.
